# Elm Community

<img
  src="./assets/tangram-runner.png"
  alt="Elm Community logo (tangram runner)"
  width="120rem">

Some `*-extra` packages that are fairly popular have come to live in
elm-community over time. These existing packages are managed by the [listed
maintainer](https://github.com/elm-community/guidelines/blob/master/maintainers.md)
on those repos, but no new packages are added under the `elm-community` name.

See [maintainer
tips](https://github.com/elm-community/guidelines/blob/master/maintainer_tips.md)
for rough guidelines on how to evolve `*-extra` packages.

If you are curious about the archived repos under the `elm-community` name,
check out the
[history](https://github.com/elm-community/guidelines/blob/master/history.md)
for some notes on how they got there.

General issues about this organization are managed in the [Guidelines issue
tracker](https://github.com/elm-community/Guidelines/issues).
